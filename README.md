# Utility-File
The Utility file is a file I add whenever I create a new project. It is a general purpose class which contains a plethora of 'helper" functions that I use to generate noise, sort lists, read and write files, and more.


A guide on usage is included below

//  Structs
//  Used for specialized purposes within the class
//    Coords: Intended for pointing to indices within 2D arrays


FILES: Used for uploading, downloading and manipulating files and file access from within the program.
LISTS: Used for manipulating 1 dimensional lists and storage structures.
MATRICIES: Used for manipulating 2 dimensional lists and storage structures. 
PERLIN: Used for generating and manipulating random noise.
IMAGEHANDLER: Used for manipulating images.
